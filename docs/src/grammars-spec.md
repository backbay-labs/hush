# Grammars

The full normative grammar collection is at [`spec/hushspec-grammars.md`](https://github.com/backbay-labs/hush/blob/main/spec/hushspec-grammars.md).

It gathers, in ABNF, the string forms the family defines: normalized paths and path globs, normalized hosts and host patterns, tool identifiers, rule paths and the reserved engine rule identifiers, control-mapping paths, capability and counter identifiers, version strings, the regex profile, the YAML profile checklist, detector identifiers, and media types. Every production carries examples that must and must not match, and cites the fixture that pins it where one exists.
