# Errata Process

The full process is at [`spec/errata.md`](https://github.com/backbay-labs/hush/blob/main/spec/errata.md).

An erratum corrects prose without changing behavior. File it as an issue titled `Erratum: <specification> <section>`; it is numbered `E-<year>-<n>`, resolved by a prose-only pull request, folded into a patch version, and recorded in the affected specification's change appendix. When implementations disagree, the conformance vectors decide.
