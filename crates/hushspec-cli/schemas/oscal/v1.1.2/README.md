# OSCAL 1.1.2 schemas

Unmodified National Institute of Standards and Technology release assets from
https://github.com/usnistgov/OSCAL/releases/tag/v1.1.2.
`SHA256SUMS` pins the exact downloaded bytes. The complete upstream license is
included as `LICENSE.md`, from the same release tag.

These schemas are embedded for offline validation with Draft 7 and format
validation enabled. They are not modified to weaken pattern constraints.
Schema validity is separate from Hush's supported local-reference subset and
does not establish control satisfaction or an assessment conclusion.
